# 业务原型参考

原型用于提出候选闭环，不代表用户已选择。根据题目选择一个主原型，必要时配置少量辅助原型。

| 原型 | 常见题目词 | 最小闭环 | 标志性交互 |
|---|---|---|---|
| 档案资产 | 档案、资产、设备、资源 | 建档→维护→变更→查询→归档 | 列表、详情、关联记录、时间线 |
| 申报审批 | 申报、申请、审核、审批 | 草稿→提交→审核→退回/通过→归档 | 分步表单、审批工作台、流程轨迹 |
| 任务执行 | 计划、任务、巡检、作业 | 计划→生成任务→执行→提交→检查 | 待办、任务看板、执行页 |
| 预约排期 | 预约、排班、调度 | 资源配置→时段→申请→冲突校验→确认/取消 | 日历、时间轴、冲突提示 |
| 运维工单 | 报修、维护、运维、工单 | 报告→派单→接单→处理→验收→关闭 | 工单列表、状态时间线 |
| 监测预警 | 监测、预警、风险、安全 | 数据→指标→规则→事件→确认→处置→解除 | 趋势、规则配置、事件中心 |
| 项目过程 | 项目、课题、工程、研发 | 立项→计划→执行→变更→验收→归档 | 里程碑、进度、项目全景 |
| 教学测评 | 教学、学习、训练、考试 | 资源→学习/训练→测评→反馈 | 课程、答题、成绩分析 |
| 内容资源 | 内容、知识、素材、文档 | 创建→分类→审核→发布→检索→下架 | 编辑器、资源库、版本记录 |
| 分析决策 | 分析、评价、预测、决策 | 数据→清洗→计算→结果→解释→反馈 | 仪表盘、对比、钻取、报告 |
| 合同履约 | 合同、采购、履约 | 起草→审批→签订→节点履约→提醒→归档 | 合同详情、履约节点、风险提示 |
| 服务受理 | 咨询、投诉、诉求、服务 | 受理→分类→分派→办理→反馈→评价 | 服务单、办理记录、满意度 |

选择原型时记录：主原型、辅助原型、题目匹配词、最小闭环、领域专属实体、被排除的通用能力和选择证据。
